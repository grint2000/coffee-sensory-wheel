## 확인 범위와 한계

- 전체 표를 확인한 정량 사례는 다른 시료 열·단위를 섞지 않았다. 우롱차는 원문 Table 1이 농도 기준으로 매긴 번호를 사용하며 원문에 없는 수치는 표시하지 않는다.
- 인동 꽃은 최고 FD 동률 성분 4개 중 3개를 표시한다. 데칸산도 동률임을 상세 조건에 공개한다.
- 맥주·와인 메타분석은 성분별 표본 수가 달라 대표 성분으로만 수록한다. 헤이즐넛 종설 표는 동의어 행의 충돌값 때문에 전체 OAV 순위를 채택하지 않았다.
- 아몬드는 로스팅·저장, 밤은 로스팅, 호두는 호두유 산화 품질 연구다. 식품명만 보고 생커널 전체 자료라고 일반화하지 않는다. Cypress·Eucalyptus는 잎 정유, Cedar·Sandalwood·Pine은 목재/심재 자료로 부위를 명시했다.
- 원문 동정명의 모호성(예: α-terpinolene, 3-furaldehyde, linalool oxide I, caryophyllene isomer)을 임의로 다른 분자·입체배치로 보정하지 않는다. 혼합명 시트랄은 개별 분자 순위에 넣지 않는다.
- 기문·다즐링·아삼·실론의 결과를 모든 홍차에 복사하지 않는다. 장미·바닐라·코코넛·포도 등도 하위 색상·가공 변형에 자동 상속하지 않는다.
- 공개 초록만 확인한 자료는 아래에 구분하며, 상세 분석법이나 전체 순위를 검증했다고 주장하지 않는다. 나머지 원문은 PMC/Europe PMC XML 또는 Orange PDF에서 해당 표·문단·분석법을 확인했다.
- 290개 미확보 항목은 개별 문헌 검토가 완료된 상태가 아니다. 계열·감각 표현·특정 배합 제품을 포함하며, 미확보를 향분자 부재로 해석하지 않는다.
