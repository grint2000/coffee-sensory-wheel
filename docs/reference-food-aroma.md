# 참고 식품 향기 성분 데이터

## 원문 확인 범위

2026-10-31에 Bozova et al. (2025), DOI `10.3934/agrfood.2025003`의 원문 PDF Table 7(p.48, PDF p.9), Methods §§2.1, 2.3, 2.5–2.6(pp.42–44)을 텍스트와 표 이미지로 대조했다. Navelina, 1차 수확, CP 열의 10개 동정 성분과 Undefined 행을 옮겼다. 행 순서가 아니라 FID 상대 조성값으로 내림차순을 계산한다.

| 성분 원문명 | CP 상대 조성(%) |
| --- | ---: |
| α-Pinene | 0.5 |
| Sabinene | 0.2 |
| δ-3-Carene | 0.2 |
| β-Myrcene | 2.0 |
| Limonene | 96.4 |
| β-Phellandrene | 0.3 |
| Terpinolen | 0.1 |
| Octanal | 0.1 |
| Decanal | 0.1 |
| Linalool | 0.1 |
| Undefined | 0.0 |

Undefined는 개별 분자가 아니므로 순위에서 제외한다. Terpinolen은 동의어 테이블의 Terpinolene으로 동정하되 원문 표기도 데이터에 보존했다. Limonene을 입체이성질체가 명시된 D-limonene으로 임의 변경하지 않는다. 껍질 정유 수율(mL/100 g)과 정유 내부의 FID 상대 조성(%)은 다른 값이다. 96.4%를 생오렌지 100 g의 리모넨 질량이나 향 기여율로 읽지 않는다.

GC-FID 상대 조성 1위 리모넨 96.4%, 2위 베타-미르센 2.0%, 3위 알파-피넨 0.5%는 이 열의 시료에만 적용한다. 다른 품종·수확·추출법·과즙·헤드스페이스 자료와 합치지 않는다. 원문에 적힌 온도 프로그램은 계산상 30분인데 총 분석시간은 60분으로 기재돼 있다. 이 불일치는 상세 조건에 밝히고 임의 보정하지 않았다.

대표 성분만 표시하는 7개 항목은 El Hadi et al. (2013), *Advances in Fruit Aroma Volatile Research*, DOI `10.3390/molecules18078200`, PMCID `PMC6270112`, §2.2의 해당 식품 문단을 원문 XML로 확인했다. Apple은 Fuji 문단 [27], Pear [34], Strawberry [47], Banana [50], Peach [65], Grape [72], Raspberry [76]을 가리킨다. 종설에 이름이 명시된 성분만 채택하고 동일 시료군의 정량 표는 아직 채택하지 않았으므로 함량 순위를 부여하지 않는다. 품종·부위·상태가 미지정된 경우 그대로 표시한다.

## 계산과 매핑 규칙

- 같은 출처·식품·품종·부위·상태·수확·시료군·표 열·단위·분석 기준의 값만 비교한다. 기준이 다른 행이 섞이면 데이터셋의 순위를 확정하지 않는다. 단위를 자동 변환하거나 GC-FID와 GC-MS 상대량을 합치지 않는다.
- 숫자가 큰 순서로 경쟁 순위(1, 1, 3)를 부여한다. 3위에서 동률이면 동률 성분을 모두 표시하므로 3행을 넘을 수 있다. 반올림된 보고값의 동률이며 통계적 동일성 주장은 아니다.
- 결측·범위·검출한계 값, 음수·비유한 값, 충돌하는 중복 값에는 숫자 순위를 부여하지 않는다. 누락을 0으로 바꾸지 않는다. 양이 없는 대표 성분 목록에도 숫자 순위를 붙이지 않는다.
- 동일 분자의 확인된 동의어와 동일 값을 한 번만 표시한다. 중복 값이 다르면 큰 값을 임의 채택하지 않는다. 혼합·동시 용출 피크와 미동정 피크는 개별 분자로 분리해 순위에 넣지 않으며 처리 이유를 상세 조건에 표시한다. 순위는 동정된 개별 성분 내 비교다.
- 식품별 정확한 저장 키로만 매핑한다. 상위 계열이나 다른 식품의 공통 성분을 하위 항목에 복제하지 않는다. 비식품·결점·배전도·미네랄·추상 계열은 적용 대상 아님으로 분리하고, 식품 자료를 확인하지 못한 항목은 자료 미확인으로 남긴다.
- 기존 분류가 결점이어도 감자처럼 실제 식품을 가리키면 자료 미확인으로 관리한다. 커피에서의 결점·분자 검출 여부 때문에 식품 자료를 제외하지 않는다.
- OAV, 논문 수, 커피 검출 여부, 기존 근거 등급은 성분량 계산에 사용하지 않는다.
