# 참고 식품 향기 성분 데이터

## 원문 확인 범위

2026-10-31에 Bozova et al. (2025), DOI `10.3934/agrfood.2025003`의 원문 PDF Table 7(p.48, PDF p.9), Methods §§2.1, 2.3, 2.5–2.6(pp.42–44)을 텍스트와 표 이미지로 대조했다. Navelina, 1차 수확, CP 열의 10개 동정 성분과 Undefined 행을 옮겼다. 행 순서가 아니라 FID 상대 조성값으로 내림차순을 계산한다.

| 성분 원문명 | CP 상대 조성(%) |
| --- | ---: |
| α-Pinene | 0.5 |
| Sabinene | 0.2 |
| δ-3-Carene | 0.2 |
| β-Myrcene | 2.0 |
| Limonene | 96.4 |
| β-Phellandrene | 0.3 |
| Terpinolen | 0.1 |
| Octanal | 0.1 |
| Decanal | 0.1 |
| Linalool | 0.1 |
| Undefined | 0.0 |

Undefined는 개별 분자가 아니므로 순위에서 제외한다. Terpinolen은 동의어 테이블의 Terpinolene으로 동정하되 원문 표기도 데이터에 보존했다. Limonene을 입체이성질체가 명시된 D-limonene으로 임의 변경하지 않는다. 껍질 정유 수율(mL/100 g)과 정유 내부의 FID 상대 조성(%)은 다른 값이다. 96.4%를 생오렌지 100 g의 리모넨 질량이나 향 기여율로 읽지 않는다.

GC-FID 상대 조성 1위 리모넨 96.4%, 2위 베타-미르센 2.0%, 3위 알파-피넨 0.5%는 이 열의 시료에만 적용한다. 다른 품종·수확·추출법·과즙·헤드스페이스 자료와 합치지 않는다. 원문에 적힌 온도 프로그램은 계산상 30분인데 총 분석시간은 60분으로 기재돼 있다. 이 불일치는 상세 조건에 밝히고 임의 보정하지 않았다.

기존 대표 성분 7개(Apple, Pear, Strawberry, Banana, Peach, Grape, Raspberry)는 El Hadi et al. (2013), DOI `10.3390/molecules18078200`, §2.2의 해당 식품 문단을 유지한다. 이번 확장에서는 같은 문헌의 다른 식품 문단과 꽃·정유·허브·향신료·차·곡물·버섯·발효식품 문헌을 추가 검토했다. 총 43개 고유 DOI를 사용한다. 원문 전체를 확인한 자료와 공개 초록만 확인한 자료는 출처의 검토 범위로 구분한다.

## 수록·순위 규칙

- 함량·농도·퍼센트는 필수 조건이 아니다. 참고 재료 자체의 주요 성분 또는 문헌에서 확인된 향기 활성 성분을 최대 3개 제공한다. 확인된 성분이 1~2개면 그 수만 표시한다.
- 원문에서 순서가 확인돼야 1~3위 또는 공동 순위를 부여한다. `sourceRank`는 원문의 순서를 기록한 필드이며 목록 배열을 뒤집어도 순위는 유지된다. 단순한 나열·논문 수·판별 통계·기존 커피 근거 등급을 순위로 바꾸지 않는다.
- **조성·농도**, **OAV(농도/냄새 역치)**, **FD(최종 감지 희석배수)**를 각각 표시한다. OAV·FD는 함량 순위 또는 향 기여율(%)이 아니다. GC 상대 조성도 실제 질량 함량이나 향 기여율이 아니다.
- 같은 재료·품종·부위·가공 상태·시료군·표 열·단위·분석 기준 안에서만 순서를 비교한다. 원문의 시료군 평균 순위를 사용할 때는 그 시료군과 평균값임을 명시한다. 성분마다 표본 수가 다른 메타분석이나 겹치는 정량 범위에서는 대표 성분만 제공한다.
- 양이 없어도 명시적인 원문 순서가 있으면 순위를 제공한다(우롱차). 순서가 불명확하면 **대표 향기 성분 · 순위 미확정**으로 표시한다.
- 동률은 경쟁 순위(1, 1, 3)를 사용한다. 최대 3개 표시 조건을 지키며, 생략된 동률 성분이 있으면 상세 조건에 설명한다. 인동 꽃은 FD 625 공동 1위 4개 중 3개를 표시하며 데칸산도 동률임을 밝힌다.
- 결측·범위·검출한계·충돌값은 0으로 바꾸거나 임의로 큰 값을 택하지 않는다. 확인된 동의어는 중복 제거한다. 혼합명(예: Citral)은 혼합명이라고 설명하고 개별 분자로 분할하거나 순위를 주지 않는다. 원문 동정명의 이성질체·철자 모호성은 별도로 표시한다.
- 모든 성분은 참고 재료·학명/알려진 품종·부위·상태·출처·확인 위치를 연결한다. 성분별 접기 영역에서 확인할 수 있다. 출처에 미지정된 조건을 추정해 채우지 않는다.
- 저장 키에 정확히 대응하는 매핑만 사용한다. 식품 계열의 공통 목록을 하위 항목에 복사하지 않는다. 중복 분류의 같은 재료(코코넛, 페퍼민트 등)는 같은 자료를 연결하되 측정 상태를 명시한다.
- 꽃·목재·허브·향신료도 자료가 있으면 정상 표시한다. 커피에서의 검출은 필수 조건이 아니다. 신뢰할 자료가 아직 확보되지 않은 모든 항목은 **업데이트 예정**으로 표시한다. 성분이 존재하지 않는다는 뜻이 아니다. 이전의 `not-applicable` 일괄 제외 규칙을 제거했다.
